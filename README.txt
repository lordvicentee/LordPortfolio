LORD VINCENT YANA — FREE PORTFOLIO WEBSITE

FILES
- index.html: the complete responsive website. No build tools or paid services required.

EDIT BEFORE PUBLISHING
1. Open index.html in a text editor (Notepad or VS Code).
2. Replace YOUR_EMAIL@example.com with your professional email address.
3. Replace the sample YouTube/Behance/LinkedIn links with links to your real work and profiles.
4. Update each project title and description. The sample image links are remote demo images; you can replace them with your own approved images.
5. Save the file.

PUBLISH FOR FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account: https://github.com
2. Create a NEW PUBLIC repository named exactly: YOUR-GITHUB-USERNAME.github.io
   Replace YOUR-GITHUB-USERNAME with your GitHub username.
3. Choose Add file > Upload files, then upload index.html from this folder.
4. Click Commit changes.
5. Open the repository's Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch; select branch main and folder /(root), then Save.
7. Wait a few minutes, then visit https://YOUR-GITHUB-USERNAME.github.io

IMPORTANT
- A public GitHub repository and published Pages site are visible to everyone. Do not upload private client files, unreleased footage, passwords, or personal documents.
- GitHub Pages is for static websites. This template uses HTML/CSS/JavaScript and does not need a server.
- Use YouTube/Vimeo embeds or links for full-length video; do not upload large video files into the repository.
- You do not need to buy a custom domain. The github.io address is free.
